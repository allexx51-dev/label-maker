Label Maker 3 — наклейки для электрощита

Программа печатает диспетчерские надписи на панель щита под модульные аппараты: обозначение сверху, назначение линии снизу. Ширина каждой наклейки равна ширине аппарата. Из той же таблицы — маленькие наклейки на сами аппараты: панель сняли, надписи остались. Результат — PDF для печати в масштабе 1:1.

Схему рисовать не нужно, бренд аппаратов не важен. Заполните таблицу Excel в пять колонок — обозначение, три строки описания, число модулей — и получите лист наклеек. Подходит и для нового щита, и для перемаркировки старого. Таблицу можно набить прямо у щита, хоть с телефона.

Без подписки и без ограничений: сколько листов нужно, столько и печатаете. Программа и файлы остаются у вас.

Если щит спроектирован в AutoCAD Electrical, отчёт из него загружается напрямую, без перепечатки.

Для Windows, Python не нужен. Исходный код, пример таблицы и обсуждение — на GitHub.

1. Что понадобится

  • Windows 10 или 11. На Linux и macOS программа тоже запустится, пути к шрифтам там другие.
  • Python 3.9 или новее с сайта python.org.
  • Четыре библиотеки Python: reportlab (создание PDF), pandas (чтение таблиц), openpyxl (формат .xlsx), pillow (картинка предпросмотра).
  • Шрифт ISOCPEUR.ttf — чертёжный шрифт, как в AutoCAD. Он ставится вместе с AutoCAD и лежит в C:\Windows\Fonts. Без него программа возьмёт Arial.

2. Установка

2.0. Быстрый способ: готовый exe

  1. Скачайте LabelMaker.exe со страницы Releases.
  2. Положите его в отдельную папку, например D:\LabelMaker. Рядом программа создаст свои файлы настроек.
  3. Скопируйте туда же ISOCPEUR.ttf из C:\Windows\Fonts, если он там есть.
  4. Запустите LabelMaker.exe. Первый запуск занимает 5–10 секунд — программа распаковывается.
Windows может показать «Система Windows защитила ваш компьютер»: у бесплатных программ нет платной цифровой подписи. Нажмите Подробнее → Выполнить в любом случае. Исходный код открыт на GitHub, exe собирается из него автоматически.

Разделы 2.1–2.4 нужны, только если вы хотите запускать программу через Python.

2.1. Python

  1. Скачайте установщик с python.org и запустите.
  2. На первом экране отметьте Add python.exe to PATH. Без этой галки команда python в командной строке работать не будет.
  3. Нажмите Install Now. Модуль окон tkinter входит в стандартную установку, отдельно его ставить не нужно.
Python из Microsoft Store иногда приходит без tkinter. Если при запуске появится ошибка No module named 'tkinter', удалите эту версию и поставьте Python с python.org.

2.2. Библиотеки

Нажмите Win+R, введите cmd, нажмите Enter. В открывшейся командной строке выполните:

python -m pip install --upgrade reportlab pandas openpyxl pillow

Для старых файлов Excel формата .xls добавьте ещё одну библиотеку:

python -m pip install xlrd

Проверка, что всё на месте:

python -c "import reportlab, pandas, openpyxl, PIL, tkinter; print('OK')"

Ответ OK значит, что можно работать.

2.3. Программа

  1. Создайте папку, например D:\LabelMaker.
  2. Положите в неё label_maker.py (скачать).
  3. Положите туда же ISOCPEUR.ttf: скопируйте из C:\Windows\Fonts. Копия рядом с программой нужна, если на другом компьютере AutoCAD не установлен.

2.4. Запуск

Двойной щелчок по label_maker.py. Если файл открывается в блокноте, запустите из командной строки:

cd /d D:\LabelMaker
python label_maker.py

При первом запуске программа создаст рядом с собой файлы widths.json и settings.json. В них хранятся словарь ширин и настройки.

3.1. Таблица в Excel

Самый простой вариант — пять колонок без заголовка, по порядку:

ABCDE
1QF1ОСВЕЩЕНИЕКУХНЯ1
2QF2РОЗЕТКИГОСТИНАЯ1
3QD1УЗО-1РОЗЕТКИ2
4---
5QF3ВЫТЯЖКА1

Можно сделать заголовок в первой строке: «Обозначение», «Описание 1», «Описание 2», «Описание 3», «Ширина» — или TAG1, DESC1 и так далее. Тогда порядок колонок не важен.

  • Пустые строки программа пропускает.
  • Пустая колонка в середине таблицы, например незаполненный DESC3, остаётся на своём месте и ничего не сдвигает.
  • Если в ячейке формула, берётся значение, которое Excel сохранил при последнем пересчёте. Таблицу, собранную скриптом, откройте в Excel и сохраните, иначе такие ячейки будут пустыми.
  • --- и === в колонке TAG1 — служебные метки, см. раздел 8.

3.2. Бонус: отчёт из AutoCAD Electrical

Названия полей TAG1 и DESC1–DESC3 совпадают с атрибутами AutoCAD Electrical (ACADE), поэтому отчёт ложится в программу без переделки.

Сделайте отчёт по компонентам щита, в котором есть поля TAG1, DESC1, DESC2, DESC3 и поле, по которому определяется ширина: своё поле с числом модулей или имя блока. Имена блоков у каждого свои, из своей библиотеки, поэтому один раз внесите их в словарь ширин (раздел 6). Отчёт отсортируйте в том порядке, в каком аппараты стоят на рейках. Сохраните в .xlsx или .csv.

Строки с названием отчёта над заголовком мешать не будут: программа сама найдёт строку с заголовками колонок.

4. Загрузка и сопоставление колонок

  1. Нажмите Открыть Excel/CSV и выберите файл.
  2. Откроется окно Колонки таблицы. Программа уже угадала строку заголовка и назначение колонок; внизу видны первые строки данных.
  3. Проверьте назначения. Если программа ошиблась, выберите нужную колонку в выпадающем списке. (нет) означает, что поле останется пустым.
  4. Если заголовка в таблице нет, поставьте Строка заголовка = 0. Колонки A–E тогда читаются как TAG1, DESC1, DESC2, DESC3, Ширина, F, если есть, — как ширина на аппарат, G — как заливка.
  5. Нажмите Загрузить.

Выбор колонок программа запоминает. В следующий раз таблица с теми же заголовками разберётся так же.

Если в списке уже есть наклейки, программа спросит: Да — добавить к списку, Нет — заменить. Так можно собрать один лист из нескольких щитов.

CSV читается в кодировке UTF-8 или Windows-1251, разделитель (запятая, точка с запятой, табуляция) определяется сам.

5.3. Цвета строк

  • ширина задана числом модулей из словаря
  • ширина задана именем блока из словаря
  • ширина задана в миллиметрах
  • ширина пустая, взято значение по умолчанию
  • такого ключа в словаре нет, взято значение по умолчанию
  • текст не помещается в наклейку даже минимальным кеглем
  • служебная метка нового ряда или страницы

Красные и оранжевые строки нужно исправить до печати. При сохранении PDF программа предупредит, если они остались.

6. Ширина наклеек и словарь ширин

В колонке ширины допустимы три вида значений:

Что написаноКак понимаетсяПример → результат
целое число, которое есть в словаречисло модулей3 → 54 мм
имя, которое есть в словаретип аппарата или имя блока ACADE — то, что вы сами внесли в словарьУЗО 2P → 36 мм
любое другое числомиллиметры17,5, 17.5, 17,5мм → 17,5 мм
Число из словаря всегда считается количеством модулей. Если в словаре есть ключ 8, то 8 в таблице даст 141 мм, а не 8 мм. Наклейка в 8 мм на практике не встречается, но помнить об этом правиле нужно.

6.1. Сравнение имён

Имена сравниваются без учёта регистра и лишних пробелов. Одинаковые по виду русские и латинские буквы (А/A, В/B, Е/E, К/K, М/M, Н/H, О/O, Р/P, С/C, Т/T, Х/X, У/Y) считаются одной буквой. Поэтому АВТОМАТ 3P с латинской P найдёт запись АВТОМАТ 3Р с русской Р. В чертежах такая путаница встречается постоянно.

6.2. Словарь

Кнопка Словарь ширин открывает список всех ключей. Добавить: если ввести цифры, запись попадёт в числа модулей, если текст — в имена. Двойной щелчок по записи открывает правку ширины. Изменения сразу сохраняются в widths.json и применяются к таблице.

Изначально в словаре только числа модулей:

Модулей12345678
мм1836547188105123141

По стандарту DIN 43880 модуль равен 17,5 мм, но фактический шаг аппаратов разных производителей отличается на доли миллиметра. На длинном ряду ошибка набегает. Подгоните словарь под свои аппараты и прорези в панели: распечатайте пробный ряд, приложите к рейке, исправьте.

Имена добавляйте сами — те, которыми удобно пользоваться: АВТОМАТ 3P, УЗО 4P, РЕЛЕ НАПРЯЖЕНИЯ или имена блоков из своей библиотеки ACADE. Тогда в таблице можно писать тип аппарата, а не считать модули.

7. Наклейки на аппараты

Наклейка на самом аппарате дублирует панельную: обозначение и те же строки описания, только мельче. Когда панель снята для обслуживания, щит не становится безымянным. Таблица та же, PDF — отдельный: кнопка PDF на аппараты. Нужны не всегда, поэтому печатаются только по этой кнопке.

7.1. Размеры по умолчанию

Модулей1234больше
Ширина, мм13,731,748,867,2с тем же шагом

Высота 12 мм, полоса тега 4 мм. Наклейка «только тег» — 14×6 мм. Высота букв: тег 2,5 мм, описание 1,7 мм. Здесь, в отличие от панели, высота букв задаётся по заглавной букве — как высота текста в AutoCAD. Всё меняется в Настройки → На аппарат; ширины вводятся строкой через точку с запятой: 13.7; 31.7; 48.8; 67.2.

7.2. Режимы

  • Многомодульные — ширина наклейки по ширине аппарата: на трёхполюсный автомат — наклейка на три модуля.
  • Одномодульные — каждая наклейка в один модуль, клеится на один полюс.

Режим выбирается в Настройки → На аппарат → Режим и действует на все аппараты, кроме тех, у кого в словаре задан свой тип.

7.3. Тип аппарата в словаре

У каждого типа аппарата в Словаре ширин есть поле На аппарат:

ЗначениеЧто печатаетсяДля чего
автопо режиму из настроекобычные модульные аппараты
1 модульвсегда одномодульнаяширокие аппараты с малым местом под наклейку
только тегмаленькая наклейка с одним обозначением, без описанияцокольные реле
нетничегоаппараты, на которых места нет

Тип задаётся один раз для типа аппарата, таблица не меняется. Если ширина в таблице задана числом модулей, тип всегда «авто».

7.4. Вручную для одной строки

Колонка аппарат, мм показывает, что выйдет на аппарат: ширину, «тег» или «—» (наклейки не будет). Её можно править двойным щелчком, как ширину на панели. Ручное значение действует только на эту строку и важнее словаря и режима:

Что ввестиРезультат
пустопо словарю и режиму (как было)
число модулей из настроек: 1, 2, 3, 4ширина на столько модулей: 13,7 / 31,7 / 48,8 / 67,2 мм
другое число: 20, 17,5миллиметры
тегмаленькая наклейка с одним обозначением

Ручные значения помечены в таблице звёздочкой: 13.7 *. Чтобы вернуть автоматический расчёт, очистите ячейку. В Excel это шестая колонка — DEV_WIDTH или «Ширина на аппарат».

В предпросмотре вверху есть переключатель на панель / на аппараты.

7.5. Заливка полосы тега

Полосу с обозначением можно залить цветом — например, УЗО и автоматы под ним одним цветом, чтобы при срабатывании УЗО сразу видеть его группы. По умолчанию заливки нет; цвет задаётся каждому аппарату отдельно и печатается и на панели, и на аппарате. Описание остаётся на белом и читается как обычно.

  • Выделите строки (Ctrl/Shift + щелчок), нажмите Заливка… и выберите цвет. «Без заливки» убирает цвет.
  • Или двойной щелчок по колонке заливка в нужной строке.

Цвета: жёлтый, зелёный, голубой, розовый, оранжевый, сиреневый, серый. В Excel можно вписать название или код цвета вида #FFB74D. Нераспознанное название подсвечивается замечанием. Для заливки нужен цветной принтер: на чёрно-белом цвета превратятся в оттенки серого.

8. Ряды и листы

Наклейки ставятся слева направо. Когда следующая не помещается по ширине листа, программа начинает новый ряд. Когда ряд не помещается по высоте, начинается новый лист.

Чтобы ряды на листе совпадали с рейками в щите, используйте служебные метки в колонке TAG1:

  • --- — следующая наклейка начинает новый ряд. Ставьте между рейками.
  • === — следующая наклейка начинает новый лист. Удобно разделять панели или щиты.

Остальные колонки у служебной строки можно не заполнять. Метки вставляются кнопками Новый ряд и Новая страница.

Подпись листапустотекст в правом нижнем углу, к нему добавляется номер листа: РЩ1-П1 → РЩ1-П1-1, РЩ1-П1-2

На панели кегль — размер шрифта в миллиметрах; заглавная буква получается около 70 % от него, точная доля зависит от шрифта. На аппарате задаётся сама высота заглавной, как высота текста в AutoCAD.

10. Предпросмотр, PDF и печать

Предпросмотр рисует лист — на панель или на аппараты, по переключателю вверху окна — тем же шрифтом и по тем же размерам, что и PDF: что видно на экране, то и выйдет из принтера. Кнопки − и + меняют масштаб, колесо мыши листает страницы. Строка, выделенная в таблице, подсвечивается на листе жёлтым — так легко найти нужную наклейку. Окно можно держать открытым: оно обновляется при каждой правке.

PDF на панель и PDF на аппараты записывают каждый свой файл. Шрифт встраивается в PDF, поэтому файл печатается одинаково на любом компьютере.

Печать

  1. Откройте PDF в Adobe Reader, Foxit или браузере.
  2. В настройках печати выберите Фактический размер (Actual size) или масштаб 100 %. Режим «Подогнать по размеру страницы» уменьшит наклейки на несколько процентов, и они не совпадут с аппаратами.
  3. Первый лист напечатайте на обычной бумаге и приложите к рейке. Если шаг расходится — поправьте словарь ширин.
  4. Для щита подойдёт самоклеящаяся бумага A4 без разметки или плотная бумага под прозрачное окно панели.

11. Файлы программы

ФайлНазначение
LabelMaker.exe или label_maker.pyсама программа
ISOCPEUR.ttfшрифт; кладётся вручную
widths.jsonсловарь ширин; создаётся сам, можно переносить на другой компьютер
settings.jsonнастройки и запомненные сопоставления колонок; создаётся сам

Чтобы вернуть всё к исходному состоянию, закройте программу и удалите widths.json и settings.json.

Порядок поиска шрифта: файл, выбранный кнопкой Шрифт…; ISOCPEUR.ttf рядом с программой; isocpeur.ttf в C:\Windows\Fonts; Arial. При запуске программа проверяет, есть ли в шрифте русские буквы, и предупреждает, если их нет.

12. Проблемы и решения

Что видитеПричина и решение
'python' не является внутренней или внешней командойPython не прописан в PATH. Попробуйте py вместо python или переустановите Python с галкой Add python.exe to PATH.
No module named 'tkinter'Python из Microsoft Store или установлен без tcl/tk. Поставьте с python.org.
No module named 'reportlab' (или pandas, openpyxl, PIL)Не установлены библиотеки, см. раздел 2.2. Если Python на компьютере не один, ставьте той же командой, которой запускаете программу: py -m pip install ….
Ошибка прав при установке библиотекДобавьте ключ --user: python -m pip install --user reportlab pandas openpyxl pillow.
Файл .xls не открываетсяУстановите xlrd или пересохраните файл в Excel как .xlsx.
Предупреждение «нет кириллицы»Выбранный шрифт без русских букв. Нажмите Шрифт… и укажите другой TTF.
Все строки красныеКолонка ширины сопоставлена не с той колонкой таблицы. Загрузите файл заново и проверьте окно сопоставления.
Имена блоков из ACADE красныеТаких ключей нет в словаре. Добавьте их через Словарь ширин — один раз на каждый тип аппарата.
Оранжевая строкаТекст не помещается даже минимальным кеглем. Разбейте его на две строки описания, сократите или переключите режим на «сжать».
«Файл занят» при сохранении PDFPDF с таким именем открыт в просмотрщике. Закройте его или сохраните под другим именем.
Наклейки на бумаге уже, чем аппаратыПри печати включено масштабирование. Выберите «Фактический размер».
Расхождение копится вдоль рядаШаг в словаре не совпадает с аппаратами. Измерьте длину 10 модулей на рейке, разделите на 10 и пересчитайте словарь.
