# Label Maker 3 — наклейки для электрощита

Сайт автора: [alexkaminsky.me](https://alexkaminsky.me)

Программа печатает диспетчерские надписи на панель щита под модульные аппараты: обозначение сверху, назначение линии снизу, ширина наклейки равна ширине аппарата. Из той же таблицы — наклейки на сами аппараты: панель сняли, надписи остались. Результат — PDF для печати в масштабе 1:1.

Без подписки и без ограничений на число листов.

Схему рисовать не нужно, бренд аппаратов не важен. Достаточно таблицы Excel в пять колонок:

| TAG1 | DESC1 | DESC2 | DESC3 | Ширина |
|------|-------|-------|-------|--------|
| QF1 | ОСВЕЩЕНИЕ | КУХНЯ | | 1 |
| QF2 | РОЗЕТКИ | КУХНЯ | ЛЕВО | 1 |
| QD1 | УЗО-1 | РОЗЕТКИ | | 2 |

Ширина задаётся числом модулей, миллиметрами или типом аппарата из своего словаря. Отчёт из AutoCAD Electrical загружается напрямую: поля TAG1 и DESC1–DESC3 совпадают с атрибутами ACADE.

## Скачать

- **Windows:** `LabelMaker.exe` в разделе [Releases](../../releases/latest). Python не нужен.
- **Через Python:** `label_maker.py` из этого репозитория.

## Запуск из исходников

```
python -m pip install -r requirements.txt
python label_maker.py
```

Нужен Python 3.9+ с tkinter (стандартный установщик с python.org).

Шрифт: положите `ISOCPEUR.ttf` рядом с программой (он ставится с AutoCAD в `C:\Windows\Fonts`). Без него программа возьмёт Arial. Шрифт в репозиторий не входит — он принадлежит Autodesk.

## Возможности

- предпросмотр совпадает с PDF: оба рисуются одной функцией раскладки одним шрифтом;
- загрузка `.xlsx`, `.xls`, `.csv`; строка заголовка и назначение колонок определяются автоматически, их можно поправить;
- словарь ширин: числа модулей и свои имена (тип аппарата, имя блока ACADE); русские и латинские буквы одинакового вида при сравнении не различаются;
- длинный текст уменьшается или сжимается по ширине; что не влезло — подсвечивается;
- наклейки на аппараты отдельным PDF: многомодульные или одномодульные, «только тег» для цокольных реле, «нет» для аппаратов без места — задаётся для типа аппарата в словаре или вручную для строки;
- заливка полосы тега цветом — по выбору, для каждого аппарата (например, УЗО и его группы одним цветом);
- метки `---` (новый ряд) и `===` (новый лист) — ряды на листе совпадают с рейками в щите;
- настраиваются формат листа, поля, зазоры, высота наклейки, кегли, толщина линий, подпись листа.
